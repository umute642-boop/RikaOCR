# ADR-013: Kod Lisansı — Apache-2.0

- **Statü:** Kabul
- **Tarih:** 2026-06-29
- **Karar verenler:** Umut

## Bağlam
Kod için izin verici bir açık kaynak lisansı seçilmelidir.

## Karar
Kod **Apache License 2.0** altında lisanslanır.

## Gerekçe
Apache-2.0, MIT'in izin vericiliğine ek olarak açık **patent hibesi** ve katkı
netliği sağlar; kurumsal/akademik kullanımda güven verir.

## Sonuçlar
- `LICENSE` dosyası Apache-2.0 tam metnidir.
- Kaynak dosyalar `# SPDX-License-Identifier: Apache-2.0` başlığı taşır.
- Veri lisansı bundan bağımsızdır (bkz. ADR-014).
